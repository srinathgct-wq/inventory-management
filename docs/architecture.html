Architecture Overview

Factory Inventory Management System

A full-stack demo: a Vue 3 single-page app talking to a FastAPI backend over HTTP, backed entirely by in-memory JSON — no database.

Tech Stack

Two independently-run dev servers, connected only by REST calls over CORS.

Frontend · :3000

Client

  • Vue^3.4 · Composition API
  • Vue Router^4.3 · client-side routes
  • Axios^1.6 · HTTP client
  • Vite^5.2 · dev server / bundler
Backend · :8001

Server

  • FastAPI≥0.110
  • Pydantic≥2.5 · validation
  • Uvicorn≥0.24 · ASGI server
  • uvpackage / env manager
Data

Storage

System Architecture

Requests flow one way down the stack and back — the browser never talks to the data files directly.

Filter Data Flow

The four global filters (Time Period, Warehouse, Category, Order Status) are shared app-wide state that reshape almost every API call.

1
FilterBar.vue
User picks a filter value in the top bar.
→
2
useFilters()
Singleton composable holds shared refs (period, warehouse, category, status).
→
3
api.js
Builds a URLSearchParams query string, skipping any filter set to 'all'.
→
4
FastAPI route
Receives optional query params, e.g. warehouse, category, status, month.
→
5
apply_filters()
Filters a copy of the in-memory list; filter_by_month() handles month/quarter matching.
→
6
Pydantic response
Result is validated against a typed model and returned as JSON.
